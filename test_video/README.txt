TARUH VIDEO SAMPLE DI FOLDER INI
================================

Program mengharapkan video uji di:

    test_video/sample_vidio_2.mp4

Video TIDAK disertakan di repository GitHub (bersifat privat).
Dapatkan file-nya dari grup WhatsApp tim, lalu salin ke folder ini
dengan nama persis: sample_vidio_2.mp4

Setelah itu jalankan:

    python -m src.cli

Tanpa video ini, mode video akan berhenti dengan pesan error.
